# VOXA update

- Renamed Habla to **VOXA** with tagline **Learn by Speaking**.
- Reworked the visual theme toward the Lingonbergets Kulinariska palette: dark blue-black surfaces, lingonberry-red primary actions and restrained blue accents.
- Replaced the small conventional scenario library with **21 missions / 63 speaking exercises per language** for Spanish, Italian and German.
- New missions emphasize less conventional real-life situations: wrong train, mixed-up luggage, flea-market find, neighbor interaction, parcel mismatch, coworking trouble, rental-bike problem, museum closing, 1% phone battery, laundromat problem, broken key/lock, rain-plan change, photo help, local event, missed last bus, seat mix-up, unknown ingredient, missing clothing size, recycling rules, stopped elevator and spontaneous dog-owner small talk.
- The same generic mission engine drives all languages; content is data-driven in `languages.js`.
- Searchable phrase material is generated from the mission answers.
- Updated PWA manifest, home-screen icons, README and internal storage keys for VOXA.
- JavaScript syntax checked with Node after the update.
