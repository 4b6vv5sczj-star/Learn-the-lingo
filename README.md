# VOXA

**Learn by Speaking.** Mobilanpassad talträning i spanska, italienska och tyska. Varje språk har 20+ uppdrag och över 60 talövningar. Framsteg sparas lokalt på enheten.

## Publicera med GitHub Pages

Lägg filerna i repositoryts rot på grenen `main`. Öppna **Settings → Pages** och välj **Deploy from a branch**, `main`, `/ (root)`. GitHub visar sedan länken under **Settings → Pages → Visit site**. Filerna måste ligga tillsammans, särskilt `index.html`, `languages.js`, `manifest.webmanifest` och ikonerna.

Öppna Pages-länken i Safari på iPhone och välj **Dela → Lägg till på hemskärmen**. VOXA öppnas då med egen ikon. Ge mikrofontillstånd när du spelar in ditt första svar.

GitHub Pages publicerar sidan öppet på webben. Framsteg och inspelningar sparas lokalt på telefonen och synkroniseras inte mellan enheter.
